# Smart Farm

AI 기반 스마트팜 웹/PWA 프로토타입입니다.

## 실행 방법

1. `index.html`을 브라우저로 열면 작물 선택 화면이 시작됩니다.
2. `작물 선택 -> 품종 선택 -> 제어 대시보드` 순서로 이동합니다.
3. 로컬 서버로 볼 때는 `http://127.0.0.1:8050/index.html`을 사용하세요.

## 포함된 기능

- 작물 종류 선택 화면
- 사과처럼 작물 안에 여러 품종을 두는 품종 선택 화면
- 새 작물 종류와 새 품종 추가 UI
- 품종별 온도, 습도, 토양수분, CO2, pH, 광량 대시보드
- Device Control 목록에서 바로 켜짐/꺼짐 제어
- 장치 상세 온도/습도 슬라이더
- 문제 상황 시뮬레이션 실행 시 온도, 습도, 토양수분, CO2 중 일부 값이 계속 서서히 변함
- 자동 조절 실행 시 기준을 벗어난 항목별 장치가 자동으로 켜지고 센서값과 목표 게이지가 서서히 적정값으로 복귀
- 허용 범위를 벗어날 때만 장치가 켜지고, 목표 중앙값에 도달하면 꺼진 뒤 허용 범위 안에서는 절전 감시 유지
- 온도, 습도, 토양수분, CO2, 광량 제어에 동일한 범위 이탈-목표 복귀-절전 패턴 적용
- 현재 작물·품종·센서값과 업로드 사진을 함께 사용하는 Codex 이미지 진단
- 작물 DB 파일: `crop-database.json`, `crop-database.csv`

## 로컬 Codex 이미지 진단

공개 웹사이트는 브라우저 보안상 Codex 대화창에 직접 파일을 전송할 수 없습니다. 대신 이 PC에 로그인된 Codex CLI를 사용하는 로컬 연결기가 사진과 현재 생육 환경을 함께 분석하고 결과를 사이트로 돌려줍니다.

1. `start-local-codex-bridge.cmd`를 실행하면 로컬 Smart Farm 화면이 자동으로 열립니다.
2. 열린 연결기 창을 유지한 채 로컬 대시보드에서 사진을 선택합니다.
3. `Codex 연결됨` 표시를 확인하고 `사진 분석`을 누릅니다.

별도 OpenAI API 키는 필요하지 않지만 Codex 계정 사용량에는 포함됩니다. 연결기는 `127.0.0.1:8765`에서만 열리며, 허용된 Smart Farm 사이트와 로컬 개발 주소의 요청만 받습니다.

GitHub Pages의 공개 HTTPS 화면에서는 브라우저 보안 정책 때문에 로컬 HTTP 연결기를 직접 호출할 수 없습니다. 공개 화면의 `로컬 실행 필요` 링크로 로컬 진단 화면을 열거나 위 시작 파일을 실행하세요.
