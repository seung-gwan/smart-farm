# Smart Farm

AI 기반 스마트팜 웹/PWA 프로토타입입니다.

## 실행 방법

1. `index.html`을 브라우저로 열면 작물 선택 화면이 시작됩니다.
2. `작물 선택 -> 품종 선택 -> 제어 대시보드` 순서로 이동합니다.
3. 로컬 서버로 볼 때는 `http://127.0.0.1:8050/index.html`을 사용하세요.

## 포함된 기능

- 작물 종류 선택 화면
- 사과처럼 작물 안에 여러 품종을 두는 품종 선택 화면
- 새 작물 종류와 새 품종 추가 UI
- 품종별 온도, 습도, 토양수분, CO2, pH, 광량 대시보드
- Device Control 목록에서 바로 켜짐/꺼짐 제어
- 장치 상세 온도/습도 슬라이더
- 문제 상황 시뮬레이션 실행 시 온도, 습도, 토양수분, CO2 중 일부 값이 계속 서서히 변함
- 자동 조절 실행 시 기준을 벗어난 항목별 장치가 자동으로 켜지고 센서값과 목표 게이지가 서서히 적정값으로 복귀
- 허용 범위를 벗어날 때만 장치가 켜지고, 목표 중앙값에 도달하면 꺼진 뒤 허용 범위 안에서는 절전 감시 유지
- 온도, 습도, 토양수분, CO2, 광량 제어에 동일한 범위 이탈-목표 복귀-절전 패턴 적용
- 현재 작물·품종·센서값과 업로드 사진을 함께 사용하는 Codex 이미지 진단
- 작물 DB 파일: `crop-database.json`, `crop-database.csv`

## 로컬 Codex 이미지 진단

공개 웹사이트는 브라우저 보안상 Codex 대화창에 직접 파일을 전송할 수 없습니다. 대신 이 PC에 로그인된 Codex CLI를 사용하는 로컬 연결기가 사진과 현재 생육 환경을 함께 분석하고 결과를 사이트로 돌려줍니다.

1. `start-local-codex-bridge.cmd`를 실행하면 로컬 Smart Farm 화면이 자동으로 열립니다.
2. 열린 연결기 창을 유지한 채 로컬 대시보드에서 사진을 선택합니다.
3. `Codex 연결됨` 표시를 확인하고 `사진 분석`을 누릅니다.

별도 OpenAI API 키는 필요하지 않지만 Codex 계정 사용량에는 포함됩니다. 연결기는 `127.0.0.1:8765`에서만 열리며, 허용된 Smart Farm 사이트와 로컬 개발 주소의 요청만 받습니다.

GitHub Pages의 공개 HTTPS 화면에서는 브라우저 보안 정책 때문에 로컬 HTTP 연결기를 직접 호출할 수 없습니다. 공개 화면의 `로컬 실행 필요` 링크로 로컬 진단 화면을 열거나 위 시작 파일을 실행하세요.

## 외부 기후 기반 환기

온실 공통 목표 온도·습도를 직접 지정하면 해당 항목은 사용자 설정을 우선합니다. 모든 장치의 목표 표시가 함께 바뀌며 자동조절 시작 또는 설정 변경 시 현재값에서 새 목표로 보정합니다. 목표 도달 후 꺼지고, 사용자 설정 온도의 ±1°C 또는 습도의 ±3%p 경계에서 재가동합니다. 별도 설정이 없는 항목은 작물 권장 범위와 중앙값을 따릅니다. `권장 목표 복원`으로 기본 기준으로 돌아갑니다. 설정은 현재 대시보드 세션에 적용되며 실제 센서 모드에서는 변경할 수 없습니다.

대시보드의 온실 환기에서 농장 위도·경도를 입력하거나 현재 위치를 선택합니다. Open-Meteo의 온도, 습도, 강수, 풍속, 돌풍 추정값을 조회하고 10분마다 갱신합니다. 위치 미지정 시 명시된 시험 날씨를 사용하며, 시험 날씨 메뉴로 비·강풍·한파를 재현할 수 있습니다.

- 자동 조절을 켜면 내부 허용 범위의 경계에서 보정을 시작하고 목표 중앙값까지 유지합니다. 목표 도달 시 창문을 닫고 관련 장치를 끕니다.
- 외기가 더 시원하고 습도 조건이 맞으면 창문을 매 틱 10%씩 엽니다. 약풍(1.5 m/s 미만)에서는 배기팬이 보조합니다. 바람이 4 m/s 이상이면 개방 한도를 20%로 줄입니다.
- 외부 수증기압을 내부 온도의 상대습도로 환산하여 제습 가능성을 판단합니다. 외기가 불리하면 에어컨·히터·제습기·가습기를 사용합니다. 환기로 목표까지 도달하기 어려우면 내부 장치가 보조합니다.
- 강수, 풍속 8 m/s 이상, 돌풍 12 m/s 이상, 외기 온도가 작물 하한보다 5도 이상 낮은 경우, 기상 정보가 30분 넘게 지난 경우 창문·배기팬을 차단합니다. 이 수치는 프로토타입 설정이며 구조물 안전 인증값이 아닙니다.
- 환기 중 CO2 공급을 중지합니다. 외부 CO2는 모의 계산에서 420 ppm을 가정합니다. CO2가 높지만 안전하게 환기할 수 없으면 값이 해결된 것처럼 낮추지 않고 현장 확인을 표시합니다.
- 자동 조절을 끄면 자동 장치를 끄고 창문을 닫습니다. 시험 모드에서 수동 조작하면 자동 제어가 해제되고 직접 켠 장치가 계속 작동합니다. 수동 시험에서는 악천후 중에도 창문을 열어 영향을 비교할 수 있습니다. 자동 제어에서는 기상 차단을 적용합니다.

실내 값과 장치 동작은 시뮬레이션입니다. 실기기 제어에는 현장 강우·풍속 센서, 창문 위치 피드백, 모터 한계 스위치, 컨트롤러 통신 연결이 추가로 필요합니다. 인터넷 기상 정보만으로 실설비 안전을 판단하지 않습니다.

판단 원리 참고: [UConn 자연 환기](https://ipm.cahnr.uconn.edu/natural-ventilation-in-greenhouses/), [UMass 온실 습도 저감](https://www.umass.edu/agriculture-food-environment/greenhouse-floriculture/fact-sheets/reducing-humidity-in-greenhouse), [Open-Meteo API](https://open-meteo.com/en/docs).

검증: `node test-ventilation.cjs`. 브라우저 검증은 Playwright 설치 환경에서 로컬 브리지 실행 후 `node test-ventilation-browser.cjs`로 수행합니다.

## 실제 설비 연동

### 시험 / 실제 센서 모드

- 시험 모드는 약 1.1초마다 계산합니다. 창문이 닫혀 있어도 외기와 느리게 열·수분을 교환하며 창문·배기팬을 켜면 교환량이 커집니다. 에어컨, 히터, 가습기, 제습기, 펌프, CO2, LED 모두 수동 작동에 따라 관련 값이 변합니다. 수동 장치는 끌 때까지 모의 출력을 내며 자동 목표값은 자동 조절에서 사용합니다. 시간·출력 계수는 체험용이며 실설비 열용량을 모델링하지 않습니다.
- 실제 센서 모드는 조회 전용입니다. 모의 타이머, 시험 날씨, 수동·자동 장치 제어를 중단하며 실제 장치 명령을 보내지 않습니다. 시험에서 실제로 전환하면 시험 수치를 지우고 수신 대기를 표시합니다. 실제 장치 전원 상태도 미연결로 표시합니다.
- 센서 조회 URL은 브라우저에서 3초마다 GET 요청합니다. 응답에는 ISO 8601 형식 `measuredAt`과 숫자형 온도·습도가 필수입니다. 다른 항목은 생략할 수 있으며 수신 대기로 표시합니다. 측정값이 15초 이상 오래되거나 요청에 실패하면 현재값 표시를 중단합니다.
- 서버는 Smart Farm 출처에 대한 CORS를 허용해야 합니다. 공개 HTTPS 페이지에서는 HTTPS 센서 주소를 사용합니다. 아직 실제 센서 장비는 연결되지 않았습니다.

센서 응답 예시 (측정 시각은 실제 측정 순간으로 갱신):

```json
{
  "measuredAt": "2026-10-05T03:00:00Z",
  "sensors": {
    "temperature": 23.5,
    "humidity": 65,
    "soilMoisture": 45,
    "co2": 700,
    "soilPh": 6.0,
    "light": 7
  }
}
```

단위: 온도 °C, 습도·토양수분 %, CO2 ppm, 일조시간 h. 실제 수신 경계 검증과 전체 수동 장치 테스트: Playwright 환경에서 `node test-operating-modes.cjs`.

- 실제 센서 연동: MQTT 또는 WebSocket
- 실제 장치 제어: ESP32, Raspberry Pi, 릴레이 모듈
- 공개 사용자용 AI 이미지 진단: 서버 기반 Vision API 또는 병해충 전용 모델 연결
- 데이터 저장: SQLite, PostgreSQL, 또는 클라우드 DB
